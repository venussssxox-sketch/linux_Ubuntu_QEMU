# 已知限制与验证边界

## 设备语义

- 这是教学用共享字节队列，不提供记录边界、优先级、广播、持久化或每个打开者独立队列。
- FIFO 容量固定为 4096 字节，没有运行时调整接口。
- ioctl 仅查询状态，查询结果可能在返回后立刻被其他进程改变。
- SIGIO 使用普通信号，连续事件可能合并；应用必须重新读取设备状态。
- 设备节点模式为 `0666`，用于隔离的实验来宾，不代表生产系统权限策略。

## 平台边界

- 验证环境是 QEMU ARM64 `virt` 与 Linux 6.12.27，不是真实 ARM 开发板。
- 没有设备树外设、DMA、中断控制器、真实总线或硬件故障验证。
- 测试结论是功能和软件并发行为，不是存储、驱动或硬件性能结论。
- 模块是树外模块，加载时的 taint 标记不表示测试失败。

## 测试边界

- 已覆盖基本、边界、阻塞、信号、poll、并发、错误地址、部分拷贝、SIGIO、ioctl 和正常模块生命周期。
- 多生产者测试验证字节总量和单生产者顺序，不把单次 `write()` 当作原子消息。
- 多读者测试验证固定总量和字节内容，不承诺读者公平性。
- 部分拷贝测试依赖 Linux 用户内存复制在保护页边界返回部分成功，验证对象是当前 Linux 6.12.27 行为。
- 没有使用 KCSAN、lockdep 专项配置、故障注入或形式化验证，因此不能声称不存在所有竞态。
- 10 轮短时回归已经完成；约 8 小时稳定性测试仍待执行，不能写成已经完成。

## 工程边界

- 构建脚本固定 Buildroot 2025.02.19 与 Linux 6.12.27。
- 干净构建允许复用经过 Buildroot 哈希校验的源码下载缓存，但不复用工具链、内核、模块、测试程序或 rootfs 编译产物。
- 初次无缓存构建依赖上游下载服务和网络状态；缓存只改善可用性，不改变源码哈希检查。
