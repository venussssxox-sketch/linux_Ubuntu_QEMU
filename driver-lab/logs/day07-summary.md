## 3. 资源生命周期与接口理解

- misc_register() 注册设备，misc_deregister() 撤销注册。
- file_operations.owner = THIS_MODULE 使使用操作表的打开文件持有模块引用；正常卸载在设备使用期间被拒绝。
- release 对应 struct file 最后一个引用释放；dup 或 fork 后关闭一个 fd 不一定立即触发 release。
- release 中调用 kqueue_fasync(-1, file, 0)，移除该打开文件的异步通知订阅。
- fasync_helper() 管理订阅，kill_fasync() 发送通知；SIGIO 不传输 FIFO 内容，用户程序仍需 read()。
- 普通信号可能合并，通知不保证收到时数据仍在；程序需要处理非阻塞读取的 EAGAIN。
- ioctl 查询容量、已用量与可用空间；在 mutex 下获取一致快照，再复制到用户空间。
- 当前 FIFO、mutex 与等待队列为静态定义，没有对应的动态内存释放操作；初始化新增资源后必须同步考虑失败回滚和退出释放。
